## Derive complete street observations

Append a location operation that obtains IDs from that table and resolves their complete street observations:

```python title="city_example/tutorial.py"
@location_operation(
    name="city_streets_for_blocks", canonical=False,
    description="Select each street belonging to any supplied block once.",
    locations={"blocks": BLOCKS},
    inputs={
        "membership": Dependency(
            "membership",
            producer="city_street_membership",
        ),
    },
    output=STREET_SCHEMA, output_contract=STREETS,
)
def streets_for_blocks(
    blocks: Locations, membership: pd.DataFrame, context: LocationContext
) -> gpd.GeoDataFrame:
    del blocks
    ids = list(dict.fromkeys(membership.street_id))
    return context.resolve_locations(
        "example:city", "street", ids,
    ).to_geodataframe()
```

`LocationContext` uses the run's managed provider. Deduplicating IDs selects the shared street once; the membership table separately preserves its two allocations. Keep `canonical=False` for this chapter: the operation supplies an explicit internal dependency.

## Calculate the weighted block summary

Append the block metric's decorator. `SUMMARY` declares `block_id`, `allocated_length_m`, and `maintenance_length_m`, with one row per block:

```python title="city_example/tutorial.py"
@metric(
    name="city_block_maintenance",
    description="Allocated street lengths and maintenance workload per block.",
    locations={"blocks": BLOCKS}, inputs=block_inputs,
    outputs={"summary": SUMMARY},
)
```

Append the handler immediately after its decorator. Merge into a new table, apply the weights, and restore the requested block order:

```python title="city_example/tutorial.py"
def block_maintenance(
    blocks: Locations, parameters: MaintenanceParameters,
    maintenance: pd.DataFrame, membership: pd.DataFrame,
) -> pd.DataFrame:
    del parameters
    joined = membership.merge(
        maintenance, on="street_id", validate="many_to_one",
    )
    joined["allocated_length_m"] = joined.length_m * joined.weight
    joined["maintenance_length_m"] = joined.maintenance_length_m * joined.weight
    totals = joined.groupby("block_id")[
        ["allocated_length_m", "maintenance_length_m"]
    ].sum()
    return (
        totals.reindex(list(blocks.ids), fill_value=0.0)
        .rename_axis("block_id")
        .reset_index()
    )
```

The join uses declared identifiers, not row positions. Reindexing adds a zero row for `block-empty`, including when no street rows exist. The handler's declared parameter is forwarded to its dependency even though aggregation does not read it directly.

## Test allocation and empty inputs

Append this test to `tests/test_tutorial.py`. A threshold of 90 includes all three streets, making the shared street's allocation visible:

```python title="tests/test_tutorial.py"
def test_shared_street_allocation():
    runner = LocalRunner.from_definitions({"city": create_plugin()})
    table = runner.run("city_block_maintenance", {
        "blocks": {
            "collection": "example:city", "unit_type": "block",
            "ids": ["block-2", "block-1"],
        },
        "parameters": {"condition_threshold": 90},
    })["summary"]
    assert table.block_id.tolist() == ["block-2", "block-1"]
    assert table.allocated_length_m.tolist() == [400.0, 200.0]
    assert table.maintenance_length_m.tolist() == [400.0, 200.0]
```

Append a case whose entire derived street set is empty:

```python title="tests/test_tutorial.py"
def test_empty_block_summary():
    runner = LocalRunner.from_definitions({"city": create_plugin()})
    table = runner.run("city_block_maintenance", {"blocks": {
        "collection": "example:city", "unit_type": "block",
        "ids": ["block-empty"],
    }})["summary"]
    assert table.to_dict("records") == [{
        "block_id": "block-empty",
        "allocated_length_m": 0.0, "maintenance_length_m": 0.0,
    }]
```
