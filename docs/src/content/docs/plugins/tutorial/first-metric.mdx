Street length is the starting point for the maintenance report: it tells you how much road may need work. In this chapter, you’ll make the existing length calculation available through Lyra and check its three result rows. Start in the [prepared city project](../); you’ll measure all three streets before adding street selection in the next chapter.

<Steps>

1. ## Start with the calculation

   The supplied calculation measures each street’s projected centreline and keeps its ID beside the length. Later, you’ll use those IDs to match lengths with condition scores:

   <CodeExample path="examples/city-plugin/city_example/calculations.py" region="lengths" lang="python" meta="{7-9}" />

   The data uses metre coordinates in EPSG:32614. The function measures those coordinates directly. Your own calculation must use a coordinate system appropriate for its measurements.

1. ## Declare the output

   Other calculations need to know which columns they can expect from your result. The supplied `LENGTHS` declaration describes the `lengths` table: a string street ID and a length in metres. Lyra uses this Pandera schema to check the returned columns:

   <CodeExample path="examples/city-plugin/city_example/schemas.py" region="lengths" lang="python" meta="{2-6}" />

   The `column` helper records each column’s type, description, and unit for Pandera and Lyra to use. IDs have no unit; `length_m` uses `Unit.METRE`. Read [output declarations](../../outputs/) for the equivalent direct Pandera syntax.

1. ## Register the adapter

   Create `first_metric.py` in the example project. Import the existing calculation, data loader, and output declaration:

   ```python title="first_metric.py"
   import pandas as pd
   from lyra.runtime.local import LocalRunner
   from lyra.sdk import PluginDefinition, metric

   from city_example.calculations import calculate_lengths
   from city_example.data import load_city, street_frame
   from city_example.schemas import LENGTHS
   ```

   Add the wrapper below to `first_metric.py`. This adapter calls your existing calculation, while `@metric` gives it a name and declares the table it returns. Those declarations form its contract: the inputs and outputs Lyra checks when running it.

   The `first_plugin()` function is a factory, a function that returns a plugin definition listing the calculations to register:

   <CodeExample path="examples/city-plugin/city_example/checkpoints.py" region="first" lang="python" title="first_metric.py" meta="{4,12,17}" />

   `city_street_lengths` names the metric, `lengths` names its whole output table, and `length_m` names a column. Listing the function in the factory makes it available to the runner.

1. ## Run and inspect the table

   Add this call to `first_metric.py` to create a runner, request the length calculation, and print its result rows:

   ```python title="first_metric.py" {2-3}
   runner = LocalRunner.from_definitions({"city": first_plugin()})
   tables = runner.run("city_street_lengths", {})
   print(tables["lengths"].to_dict("records"))
   ```

   Run the script, or the equivalent supplied checkpoint:

   ```sh
   uv run python first_metric.py
   uv run python -m city_example 1
   ```

   The named table contains these values:

   | street_id | length_m |
   | --- | --- |
   | street-1 | 100.0 |
   | street-2 | 200.0 |
   | street-3 | 300.0 |

   Each row pairs a street with its measured length, ready for the maintenance calculation to use later. `LocalRunner` checks the request and result, then returns a dictionary of pandas tables. The empty input dictionary is valid because this version always loads all three streets.

1. ## Test the first result

   Create `tests/test_first_metric.py`. Run the factory through Lyra and check both the known lengths and the street IDs they belong to:

   ```python title="tests/test_first_metric.py" {8-11}
   from lyra.runtime.local import LocalRunner
   from first_metric import first_plugin


   def test_lengths_match_the_fixture():
       runner = LocalRunner.from_definitions({"city": first_plugin()})
       table = runner.run("city_street_lengths", {})["lengths"]
       assert table.street_id.tolist() == [
           "street-1", "street-2", "street-3",
       ]
       assert table.length_m.tolist() == [100.0, 200.0, 300.0]
   ```

   Run `uv run pytest tests/test_first_metric.py`. Keep this test when extending the plugin; it establishes the values the later reports reuse.

</Steps>
