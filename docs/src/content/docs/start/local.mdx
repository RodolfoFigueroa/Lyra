Try a street-maintenance calculation that reports how many metres of road need work. You’ll run the supplied city plugin, inspect one street’s result, and change the threshold to see how the decision changes. You need Python 3.11 or later, uv, and a Lyra checkout; the example includes its data and needs no database, credentials, or server.

<Steps>

1. ## Prepare the example environment

   From the repository root:

   ```sh
   cd examples/city-plugin
   uv sync
   ```

   The project installs Lyra’s software development kit (SDK) and the libraries used by the calculations. Its data contains three streets with known lengths and synthetic condition scores.

1. ## Select and run a calculation

   Create `first_metric.py` in the example project. `create_plugin()` supplies the available calculations, and `LocalRunner` runs them in your Python process. The request below chooses `street-1` and asks for maintenance when its condition score is below 50:

   ```python title="first_metric.py" {5-12}
   from city_example import create_plugin
   from lyra.sdk import LocalRunner

   runner = LocalRunner.from_definitions({"city": create_plugin()})
   tables = runner.run("city_street_maintenance", {
       "streets": {
           "collection": "example:city", "unit_type": "street",
           "ids": ["street-1"],
       },
       "parameters": {"condition_threshold": 50},
   })
   print(tables["maintenance"][["street_id", "maintenance_length_m"]])
   ```

   Run `uv run python first_metric.py`. The table identifies `street-1` and reports 100 m of maintenance workload. Its synthetic condition score is 20, below the threshold 50. The runner returns a dictionary of pandas tables; `tables["maintenance"]` selects the result table named by this metric.

1. ## Change the selection or threshold

   Change the ID in the request to `street-2` and run the script again. Its score is 80, so the result is zero workload at threshold 50. Raise the threshold to 90 to include its 200 m length. A score equal to the threshold requires no maintenance.

   The calculation runs in your process and creates no retained server job. Follow [local execution](../../use/local-execution/) for installed plugins, resources, and caching. To implement the calculation yourself, start [Build a city analysis plugin](../../plugins/tutorial/).

</Steps>
